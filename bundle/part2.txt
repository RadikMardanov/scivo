# SCIVO — PROJECT PASSPORT (v1.2)

## Decisions (approved by PO)
- Test format: Web link (PWA) via GitHub Pages: https://radikmardanov.github.io/scivo/
- Audience: families in Russia, children 7–10 (grades 1–4)
- Accounts: family model. Only parent has email/password (Supabase Auth).
  Children = rows in `children` (nickname, avatar, grade, 4-digit PIN hashed on server).
  Parent zone: parental gate (multiplication task) + parent PIN (server-verified).
- AI: no LLM in v1. Rule-based "Scivo Brain" (stage 4). LLM-ready JSON contract for v2.
- Voice: flutter_tts + speech_to_text (stage 4), keypad fallback.
- Graphics: SVG by Illustrator role (lib/art). Avatars = recolored Scivo raven (6 colors).
- Font: Nunito (Quicksand has no Cyrillic).
- Notifications: in-app + email via Yandex SMTP (stage 5).
- Data minimization: parent email; child nickname, avatar, grade. Consent in parents.consent_at.
- Worlds v1: Forest of Counting, Bridge of Numbers, Cave of Multiplication, Clock Tower, Fractions of Chaos.
- Answers and rewards: server-side only (SQL RPC). Client never writes balances.

## Delivery pipeline
- PO pastes bundles into bundle/partN.txt (repo root). One part per chat message (size limit).
- Workflow unpacks, commits, builds Flutter Web, deploys to Pages.
- Bundles may NOT write into .github, .git or bundle folders.
- Never name our tests widget_test.dart (CI deletes that file).

## App structure (stage 2)
- State: flutter_riverpod 2.x.
- AuthGate: no session -> AuthScreen; no consent -> ConsentScreen; no parent PIN -> ParentPinSetupScreen;
  no children -> AddChildScreen(isFirst); no active child -> ProfilePickerScreen; else ChildShell.
- ChildShell: onboarding (once, +20 mana) -> daily checkin (+5 mana, streak) -> tabs Games / Wishlist / Profile.
- Client selects explicit columns on parents/children (column-level grants).

## Stages
0 Accounts & checks — DONE
1 DB & security — DONE
2 App skeleton (parts 2–5) — IN PROGRESS
3 Quest engine + 5 worlds + mechanics
4 Scivo Brain + voice
5 Parent dashboard, wishlist, limits, email
6 QA & polish, PWA icons

import 'package:flutter_riverpod/flutter_riverpod.dart';

import 'core/config/env_config.dart';

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();

  String? initError;
  if (!EnvConfig.isConfigured) {
    initError = 'Не заданы SUPABASE_URL и SUPABASE_ANON_KEY.';
  } else {
    try {
      await Supabase.initialize(
        url: EnvConfig.supabaseUrl,
        anonKey: EnvConfig.supabaseAnonKey,
      );
    } catch (error) {
      initError = error.toString();
    }
  }

  runApp(ProviderScope(child: ScivoApp(initError: initError)));
}

class ScivoApp extends StatelessWidget {
  const ScivoApp({super.key, this.initError});

  final String? initError;

  @override
  Widget build(BuildContext context) {
    final error = initError;
    return MaterialApp(
      title: 'Scivo',
      debugShowCheckedModeBanner: false,
      theme: AppTheme.dark(),
      home: error == null
          ? const AuthGate()
          : Scaffold(
              body: MagicBackground(
                child: SafeArea(
                  child: ErrorView(message: 'Не удалось запустить магию: $error'),
                ),
              ),
            ),
    );
  }
}

class PinCheckResult {
  const PinCheckResult({
    required this.ok,
    this.reason,
    this.attemptsLeft,
    this.lockSeconds,
  });

  final bool ok;
  final String? reason;
  final int? attemptsLeft;
  final int? lockSeconds;

  factory PinCheckResult.fromJson(Map<String, dynamic> json) {
    return PinCheckResult(
      ok: json['ok'] == true,
      reason: json['reason'] as String?,
      attemptsLeft: (json['attempts_left'] as num?)?.toInt(),
      lockSeconds: (json['seconds'] as num?)?.toInt(),
    );
  }

  String get message {
    switch (reason) {
      case 'locked':
        return 'Слишком много попыток. Подождите ${lockSeconds ?? 60} сек.';
      case 'no_pin':
        return 'PIN родителя ещё не задан.';
      default:
        final left = attemptsLeft;
        if (left != null) return 'Неверный PIN. Осталось попыток: $left';
        return 'Неверный PIN.';
    }
  }
}

import 'package:supabase_flutter/supabase_flutter.dart';

import '../core/errors.dart';
import '../models/family_models.dart';

class SupabaseService {
  SupabaseService(this._client);

  final SupabaseClient _client;

  Session? get currentSession => _client.auth.currentSession;
  Stream<AuthState> get authChanges => _client.auth.onAuthStateChange;

  // ---------- Аккаунт родителя ----------
  Future<void> signUpParent({
    required String email,
    required String password,
    required String displayName,
  }) async {
    await _client.auth.signUp(
      email: email.trim(),
      password: password,
      data: {
        'display_name': displayName.trim(),
        'consent': 'true',
      },
    );
  }

  Future<void> signIn(String email, String password) async {
    await _client.auth.signInWithPassword(
      email: email.trim(),
      password: password,
    );
  }

  Future<void> signOut() => _client.auth.signOut();

  Future<ParentProfile?> fetchParent() async {
    final userId = _client.auth.currentUser?.id;
    if (userId == null) return null;
    final row = await _client
        .from('parents')
        .select('id, display_name, has_pin, consent_at')
        .eq('id', userId)
        .maybeSingle();
    return row == null ? null : ParentProfile.fromJson(row);
  }

  Future<void> giveConsent() async {
    await _client.rpc('give_consent');
  }

  Future<void> setParentPin(String pin) async {
    final result = await _client.rpc('set_parent_pin', params: {'p_new_pin': pin});
    final check = PinCheckResult.fromJson(Map<String, dynamic>.from(result as Map));
    if (!check.ok) throw AppException(check.message);
  }

  Future<PinCheckResult> verifyParentPin(String pin) async {
    final result = await _client.rpc('verify_parent_pin', params: {'p_pin': pin});
    return PinCheckResult.fromJson(Map<String, dynamic>.from(result as Map));
  }

  // ---------- Дети ----------
  Future<List<ChildProfile>> fetchChildren() async {
    final rows = await _client
        .from('children')
        .select('id, nickname, avatar_id, grade, onboarding_done, daily_feather_cap')
        .order('created_at');
    return rows.map((row) => ChildProfile.fromJson(row)).toList();
  }

  Future<String> createChild({
    required String nickname,
    required String avatarId,
    required int grade,
    required String pin,
  }) async {
    final result = await _client.rpc('create_child', params: {
      'p_nickname': nickname.trim(),
      'p_avatar_id': avatarId,
      'p_grade': grade,
      'p_pin': pin,
    });
    return result.toString();
  }

  Future<PinCheckResult> verifyChildPin(String childId, String pin) async {
    final result = await _client.rpc('verify_child_pin', params: {
      'p_child_id': childId,
      'p_pin': pin,
    });
    return PinCheckResult.fromJson(Map<String, dynamic>.from(result as Map));
  }

  // ---------- Прогресс ----------
  Future<ChildProgress> fetchProgress(String childId) async {
    final row = await _client
        .from('child_progress')
        .select()
        .eq('child_id', childId)
        .maybeSingle();
    return row == null ? ChildProgress.empty : ChildProgress.fromJson(row);
  }

  Future<CheckinResult> checkin(String childId) async {
    final raw = await _client.rpc('child_checkin', params: {'p_child_id': childId});
    final result = Map<String, dynamic>.from(raw as Map);
    return CheckinResult(
      progress: ChildProgress.fromJson(Map<String, dynamic>.from(result['progress'] as Map)),
      manaBonus: (result['mana_bonus'] as num?)?.toInt() ?? 0,
      usedFreeze: result['used_freeze'] == true,
    );
  }

  Future<int> completeOnboarding(String childId) async {
    final raw = await _client.rpc('complete_onboarding', params: {'p_child_id': childId});
    final result = Map<String, dynamic>.from(raw as Map);
    return (result['mana_bonus'] as num?)?.toInt() ?? 0;
  }

  // ---------- Вишлист ----------
  Future<List<WishlistItem>> fetchWishlist() async {
    final rows = await _client
        .from('wishlist_items')
        .select('id, title, feather_cost, emoji')
        .eq('is_active', true)
        .order('feather_cost');
    return rows.map((row) => WishlistItem.fromJson(row)).toList();
  }
}
